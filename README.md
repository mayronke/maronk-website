# Mayron — website profissional

Página estática em português, responsiva e sem dependências ou etapa de compilação.

## Conteúdo

Apresentação, serviços (WordPress, Notion, n8n e IA), proposta do projeto Human + AI Workspace e contato. Nome, e-mail e perfil GitHub foram verificados pelo conector GitHub. O texto do projeto descreve uma proposta; não afirma funcionalidades implementadas, clientes ou resultados.

## Visualizar

Abra `index.html` em um navegador, ou execute `python3 -m http.server 8000` nesta pasta.

## Publicar no GitHub Pages

1. Use o repositório https://github.com/mayronke/maronk-website.
2. Envie `index.html`, `styles.css`, `favicon.svg` e `.nojekyll` para a raiz da branch `main`.
3. Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, branch **main** e pasta **/ (root)**; clique em **Save**.
4. Aguarde a publicação e abra a URL informada pelo GitHub.

Site publicado e verificado: https://mayronke.github.io/maronk-website/

## Domínio próprio

`maronk.com.br` foi mencionado pelo proprietário, mas não foi configurado. Confirme com ele antes de criar `CNAME` ou alterar DNS.

## Editar

- Textos e links: `index.html`.
- Cores, espaçamentos e adaptação a telas: `styles.css`.
- Ícone: `favicon.svg`.

Não há formulário, cookies, analytics, fontes externas nem coleta de dados. O botão de contato abre o aplicativo de e-mail do visitante.
